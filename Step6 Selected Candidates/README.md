# Step 6: Selected candidates

## Candidate selection

For all protein sequences in the Cas12f clusters, we retrieved the corresponding genomic sequences. We then searched the regions extending 5 kb upstream and 5 kb downstream of each protein-coding gene for CRISPR-Cas arrays, with particular attention to repeat sequences longer than 15 bp. This genomic-neighborhood screening identified 17 candidate proteins.

| File | Use |
|---|---|
| [`selected_candidates.fasta`](selected_candidates.fasta) | 17 candidate protein sequences with accession IDs and descriptions |
| [`candidate_ids.txt`](candidate_ids.txt) | The same 17 IDs, one per line, for sequence extraction or accession lookup |
